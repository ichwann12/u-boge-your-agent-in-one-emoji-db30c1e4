My agent in one emoji:

> 🐜

Small, relentless, and always carrying more than its own weight — one tiny ant moving the whole anthill, one task at a time.

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the emoji from `entry.txt` at the repo root and writes it to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`).

Run it with:

```sh
node main.ts
```
